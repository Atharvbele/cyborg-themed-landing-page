# NEXUS-9 — Cyborg-Themed Landing Page

Responsive single-page cyberpunk/cyborg landing page built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop/mobile layout
- Cybernetic neon visual system with grid, scanline, noise and orbital core
- Accessible navigation and semantic sections
- CSS-only visual effects with reduced-motion support
- Interactive pointer-parallax on the hero visualization
- No framework or build step required

## Run locally
Open `index.html` directly, or run any static server, e.g. `python -m http.server 8000`.
